# MedTrace web app

**Owner:** Shrey Bishnoi (app shell, wallet connection, role pages). Patient verify page: Vaibhav Abhiramacheri.

React (Vite) + Ethers v6 + a browser wallet (MetaMask). Each supply-chain role gets its own page; patients get a read-only "Verify my medicine" page that needs no wallet.

## Pages

| Route | Who | What it does | Contract calls |
|---|---|---|---|
| `/` | Everyone | Connect your account; detects your role and sends you to your page | `hasRole`, `participantName` |
| `/factory` | Factory | Register a batch, hand it off | `registerBatch`, `transferCustody` |
| `/distributor` | Distributor | Accept deliveries, hand batches on | `confirmReceipt`, `transferCustody` |
| `/pharmacy` | Pharmacy | Accept deliveries, dispense to patients | `confirmReceipt`, `markDispensed` |
| `/regulator` | Regulator | Certify or recall any batch | `certifyBatch`, `recallBatch` |
| `/admin` | Network operator | Onboard participants | `registerParticipant` |
| `/verify` | Patient (no wallet) | Check a batch: safe or not, plus its journey | `verifyBatch`, `getBatch`, `getHistory` |

Look and feel: playful and low on text. Chunky ink outlines, hard offset shadows, Fredoka + Nunito, one colour per role (factory orange, distributor blue, pharmacy green, regulator purple, patient pink). Status colours still only mean status. Pip, a pill character, reacts to each moment (happy, waiting, party, worried, thinking, sleepy). Confetti only for good news. `prefers-reduced-motion` turns the motion off.

**The road** (custody timeline) on every batch: one station tile per holder, built from the real history, and the batch as a token. A box when held, a bouncing truck on the dashed half of the road while a hand-off waits to be accepted, a red block when recalled, a green lock once dispensed, and a flame marker where it got too warm. On the factory page you can **drag the box** toward the distributor to start a hand-off (Enter or Space does the same); the wallet still confirms it. When a delivery is accepted the truck drives into the station.

## Run it locally

From the repo root, in three terminals:

```bash
# 1. local chain
npx hardhat node

# 2. deploy + demo data (prints the contract address and one account per role)
npm run seed:local

# 3. point the app at the contract, then start it
cd frontend
npm install
npm run sync-contract -- <address printed above> localhost
npm run dev
```

Then in MetaMask add the local network (RPC `http://127.0.0.1:8545`, chain id `31337`) and import the Hardhat test accounts you want to act as. `seedDemo.js` prints which account has which role.

For the Polygon Amoy deployment: `npm run sync-contract -- <amoy address> amoy`. This also records the block the contract was deployed in (read from `deployments/amoy.json`, or pass it as a third argument). The public Amoy endpoint only searches 10,000 blocks of events at a time, so the app reads the participant list and temperature alerts in chunks from that block onward.

## Local dev mode (no wallet needed)

On the local Hardhat network only, open a page with `?as=<address>` to act as one of the node's unlocked accounts, for example `/factory?as=0x7099...79C8` (the factory from `seedDemo.js`). The app signs with that account directly, so you can click through every flow without MetaMask. Ignored on any public network.

## Recording mode

Open any page with `?record=1` to lock the layout to 1920x1080 and hide development-only elements. Honours `prefers-reduced-motion`.
